# Template: Explicacao de Condicao/Procedimento para Paciente

## Quando usar

Use este template para gerar explicacoes claras sobre doencas, procedimentos ou tratamentos em linguagem adaptada ao perfil do paciente. Ideal para materiais impressos de orientacao, mensagens pos-consulta ou preparacao de como explicar algo complexo de forma acessivel.

---

## Template (copie e cole)

```
Voce e um medico [ESPECIALIDADE] com excelente habilidade de comunicacao com pacientes.

Gere uma explicacao sobre a condicao/procedimento abaixo, adaptada ao perfil do paciente.

CONDICAO OU PROCEDIMENTO A EXPLICAR:
[NOME DA CONDICAO, PROCEDIMENTO OU TRATAMENTO]

PERFIL DO PACIENTE:
- Idade: [IDADE] anos
- Escolaridade estimada: [FUNDAMENTAL INCOMPLETO / FUNDAMENTAL / MEDIO / SUPERIOR]
- Contexto: [PACIENTE SUS / CONVENIO / PARTICULAR]
- Informacoes relevantes: [COMORBIDADES, LIMITACOES, CUIDADOR PRESENTE, ETC.]

O QUE O PACIENTE PRECISA ENTENDER:
- [TOPICO 1: ex. o que e a doenca]
- [TOPICO 2: ex. por que precisa tratar]
- [TOPICO 3: ex. como tomar a medicacao]
- [TOPICO 4: ex. sinais de alarme]
- [TOPICO 5: ex. quando voltar ao medico]

FORMATO DA EXPLICACAO:
1. Use linguagem simples, sem jargao medico. Quando usar um termo tecnico, explique entre parenteses.
2. Use analogias do cotidiano para explicar conceitos.
3. Organize em topicos curtos com subtitulos claros.
4. Inclua uma secao "Sinais de perigo — procure o pronto-socorro se:" com lista objetiva.
5. Termine com uma secao de "Perguntas que voce pode querer fazer ao seu medico" (3-5 sugestoes).
6. Extensao: no maximo 1 pagina impressa (cerca de 400 palavras).

RESTRICOES:
- Nao use termos como "voce deve" ou tom paternalista. Prefira "e importante que" ou "o recomendado e".
- Nao inclua nomes de medicamentos especificos — mantenha generico, pois a prescricao e feita a parte.
- Considere o nivel de letramento em saude do paciente.
- Respeite a autonomia do paciente.
```

## Dicas de uso

- **Imprima para o paciente**: apos revisar o texto gerado, voce pode imprimir e entregar ao paciente ou enviar por WhatsApp. Isso reforca as orientacoes dadas verbalmente na consulta.
- **Adapte a escolaridade com honestidade**: nao subestime nem superestime. Um texto para ensino fundamental incompleto precisa de frases curtas, sem subordinadas longas e com analogias concretas (mangueira com pressao alta, cano entupido, etc.).
- **Use para preparar a consulta**: antes de atender um paciente que precisara receber um diagnostico dificil, rode o template para organizar mentalmente como explicar.
- **Inclua o cuidador**: quando o paciente depende de familiar, adicione nas informacoes relevantes "cuidador presente" para que o texto tambem oriente quem cuida.

## Variacoes possiveis

| Variacao | O que mudar no template |
|---|---|
| **Explicacao de procedimento cirurgico** | Altere os topicos para: o que e o procedimento, como e feito, anestesia, tempo de recuperacao, riscos, cuidados pos-operatorios |
| **Explicacao para crianca/adolescente** | Ajuste a linguagem para a faixa etaria. Adicione: "Use tom acolhedor e inclua uma analogia ludica (ex.: super-heroi, videogame)" |
| **Explicacao para familiar de paciente em UTI** | Altere o foco para: o que esta acontecendo agora, quais aparelhos estao conectados, o que significa cada bip, horarios de visita, com quem falar |
| **Orientacao pos-alta hospitalar** | Adicione topicos: medicacoes de casa, curativos, restricoes de atividade, retorno ambulatorial, sinais de complicacao |
| **Consentimento informado simplificado** | Adicione: "Inclua ao final um paragrafo resumindo riscos e beneficios que o paciente pode usar como base para decidir se aceita o procedimento" |
