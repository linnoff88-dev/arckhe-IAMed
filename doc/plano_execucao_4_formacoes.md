### Aula 1.1.1 — "A IA é seu R1, não seu chefe"

**Analogia central:**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Pense na IA como um RESIDENTE DE PRIMEIRO ANO:           │
│                                                             │
│   ✅ Leu todos os livros (treinada em bilhões de textos)   │
│   ✅ Trabalha 24h sem reclamar                              │
│   ✅ Faz rascunhos rápidos                                  │
│   ✅ Segue instruções bem dadas                              │
│                                                             │
│   ⚠️  MAS:                                                 │
│                                                             │
│   ❌ Às vezes inventa coisas com confiança (alucinação)     │
��   ❌ Não tem experiência clínica real                       │
│   ❌ Não conhece SEU paciente                               │
│   ❌ Precisa de supervisão SEMPRE                           │
│                                                             │
│   Você nunca deixaria um R1 decidir sozinho.                │
│   Com a IA é igual.                                         │
│                                                             │
└──��──────────────────────────────────���───────────────────────┘
```

**Conteúdo:**
- O que a IA faz: reconhece padrões, gera texto, processa dados
- O que a IA NÃO faz: raciocínio clínico verdadeiro, empatia, responsabilidade
- Tipos de IA que o médico vai encontrar:
  - **IA generativa** (ChatGPT, Claude) = o R1 que escreve rascunhos
  - **IA diagnóstica** (Viz.ai, modelos de imagem) = o exame complementar digital
  - **IA administrativa** (ambient scribing) = o secretário que nunca erra a anotação

**Exercício prático:** Abra o ChatGPT ou Claude. Peça um diagnóstico diferencial para uma queixa que você atendeu hoje. Avalie: o que está certo? O que está errado? O que está perigosamente confiante?
